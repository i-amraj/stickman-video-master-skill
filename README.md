# Stickman Video Master Skill

Script writing se lekar character design, scene build, voiceover aur final mix tak — code se Hindi horror/mystery Shorts banane ki complete master skill, ek asal production (Bhangarh reel) se nikli hui.

- **SKILL.md** — poori pipeline, step by step (research → script → character → sets → render → VO → mix → QC)
- **script/** — asal script (sach/kahani tags + pacing check ke saath) — template ki tarah use karo
- **code/** — reel ka poora scene/character code + render scripts + ASSEMBLY.md
- **vo/** — voiceover fit + mix scripts (Gemini TTS Puck/Algenib, Whisper-verify method)
- **docs/** — visual system digest + hard lessons
- **demo/** — is pipeline se bani final reel: Bhangarh (49s, 1080x1920, -14 LUFS)
